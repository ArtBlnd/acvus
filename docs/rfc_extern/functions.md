# functions

An extern receives an acvus function lent for the call, as a closure parameter written in Rust's own closure bound, or kept past it, as a function value whose type is a Rust function pointer type under `#[fn_type]`. An extern gives acvus no Rust function, a closure or any other: a function value it returns is one acvus gave it.

## 1. Closure parameters

An author writes a closure parameter as Rust writes one: a `Fn`, `FnMut` or `FnOnce` bound, its arguments' lifetimes stated by elision or by a binder. Its function type and flows are those its signature writes: a result that borrows an argument borrows that argument (compiler: extern fn §4), and the closure's effect joins the call's, since the call runs it (compiler: extern fn §2). The body receives a Rust closure that calls the acvus function value through the runtime; an argument `&T` or `&mut T` crosses as a `Ref` or a `Mut`, and a result returns as an owned value, a `Ref` or a `Mut`. A `Fn` bound is no excluded trick: an acvus closure is an ordinary lambda, whose body acvus checks and whose handling of a reference its flows state. A closure so lent is the call's alone, and keeping it past the call is refused. Its bound is its function type's: `Fn` is called many times and holds no exclusive loan, since it may be called through shared borrows at once; `FnMut` is called many times, one call at a time, and may hold one; `FnOnce` is called once.

## 2. A function kept past the call

An author names a function type it keeps, once, where it writes it, as an alias of a Rust function pointer type marked `#[fn_type(mode)]`: `#[fn_type(ref)] type Pred<'f, T, E: EffectVar> = fn(&T) -> bool`. The mode is how the function is called, declared where its type is named: `ref` calls it through a shared borrow, as a `Fn` is called, `mut` through an exclusive one, as a `FnMut`, `owned` consumes it, as a `FnOnce` (§1), and `async` calls it asynchronously (§3). The signature is a Rust type, its arguments' lifetimes stated by elision or by a binder as a function pointer states them, so Rust resolves it; the mode is declared, never read from a type. The function crosses as a function value, kept as `Uniform<R, Pred<'f, T, E>>`, and is called through a view of it as a Rust closure for a scope, which borrows the runtime for that scope alone. Its effect is the alias's `EffectVar` parameter, which the declarations that keep it fill with their own variable, so a function is kept only with a variable to carry its effect (types §1). Its view calls it as its mode states: `call_ref` for `ref`, `call_mut` for `mut`, and `call_once`, which consumes it, for `owned`. `'f`, the loans the function holds, is the alias's first lifetime parameter, so a type that keeps the function declares that it holds them. The runtime contract gives no `'static` handle for it.

## 3. Asynchronous calls

An extern calls an acvus function asynchronously in place: the call runs as the future that awaits it is polled, and nothing runs it apart. A scope takes the callable and its arguments by value, lends them to the call, and gives them back with its result, so the call's flows are plain moves and what the work keeps shows in its declaration. The work a scope starts is given its loans for every loan the scope may make, so a loan from outside the scope, the caller's own or another scope's, fits none of its calls. A future is dropped only between its polls, so dropping the scope, or the call within it, abandons the call where it suspended, where every storage it was lent is whole (compiler: ownership §4), and what the scope holds is released with it. A function called asynchronously crosses as a function value, its alias marked `#[fn_type(async)]`, `#[fn_type(async)] type Fetch<'f, T, U, E: EffectVar> = fn(&T) -> U`, which declares a function type that may suspend; a closure lent for the call cannot outlive a cancellation.

*Rejected.* An alias of Rust's own closure type, `dyn Fn(&T) -> bool + 'f`, its call read from the bound it is written with: the bound is a name the macro must read before Rust resolves anything, and `dyn AsyncFn` is no Rust type. A per-call wrapper that gives a closure a fresh lifetime at each call through a family of marker types: it gives every reference argument of a call one lifetime, and its higher-ranked opener fails for a generic type. A second owner for asynchronous work: what the work uses it owns. A runtime task running the call apart, kept until the call's frame ends: it needs a spawn of a future that is not `'static`, where a call awaited in place needs none.
